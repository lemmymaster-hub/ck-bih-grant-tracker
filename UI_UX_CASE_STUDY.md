# CK BiH Grant Tracker: interface case study

## Problem and intended user

A funding and support tracker designed around the structure of Red Cross organisations in Bosnia and Herzegovina.

## Decisions visible in the implementation

Organisation-specific filters follow how a user decides which legal entity may apply. Project guidance turns a listing into an actionable concept while staying separate from personal working notes. Detailed assessments remain accessible without making every table row taller.

## Evidence

Read the actual interface and domain source in this repository. Screenshots, a narrated demo and independently observed usability results are not included in this first package. No numerical usability improvements are claimed.

Mile Vujasin defined product requirements and interface direction and iterated on implementation with AI assistance. The repository is evidence of work on the product, not a Figma portfolio or proof of a paid institutional engagement.
